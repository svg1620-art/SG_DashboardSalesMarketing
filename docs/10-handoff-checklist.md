# 10 — Чек-лист передачи проекта

Для нового разработчика/сотрудника, принимающего проект.

## Доступы, которые нужно получить

- [ ] **GitHub** — доступ к репозиторию (owner: `svg1620-art`).
- [ ] **Railway** — доступ к проекту (сервис `web` + плагин PostgreSQL, регион EU).
- [ ] **amoCRM** — доступ к аккаунту и к интеграции («Ключи и доступы») для
      просмотра/ротации `AMOCRM_TOKEN` и проверки полей/статусов.
- [ ] **Anthropic Console** — доступ к API-ключу (`ANTHROPIC_API_KEY`) для функции
      рекомендаций (console.anthropic.com → API Keys).
- [ ] Учётка **admin** в самом приложении (создаётся через
      `BOOTSTRAP_ADMIN_EMAIL`/`BOOTSTRAP_ADMIN_PASSWORD` или другим админом).

## Онбординг (первые шаги)

1. Прочитать `docs/01` … `docs/05` (обзор → БД → синк → метрики).
2. Поднять проект локально (`docs/02`) на копии/тестовой БД.
3. Прочитать `docs/08` (runbook) — типовые проблемы и их решения.
4. Открыть в Railway → Variables и сверить переменные окружения с `docs/02`.
5. Зайти в приложение админом, пройтись по всем вкладкам и странице
   «Синхронизация».

## Ключевые особенности, которые важно понять

- **Источник правды — БД**, не amoCRM-выгрузка. Дашборды считают по `deals`.
- **Когортная атрибуция** (`docs/05`) — метрики по месяцу *создания* лида.
- **Синк-сверка** удаляет исчезнувшие из воронки сделки (`docs/04`), с защитой от
  массового удаления.
- **CAC/LTV** считаются по прямым месячным тоталам затрат (`monthly_costs`),
  сверено с исходной таблицей заказчика.
- **Правки маппинга статусов и затрат не перетираются** синком.

## Открытые вопросы / возможные доработки

- **Сопоставление названий источников.** Имена рекламных кампаний в «Затратах и
  касаниях» и источники в сделках amoCRM могут различаться — там, где не
  совпадают, CPL/ROAS по конкретному источнику не сойдётся (месячные итоги
  рекламы для CAC корректны). При необходимости — сделать таблицу-алиасы
  «кампания → источник сделки».
- **Самоочистка зависших `running`-строк** в `sync_log` (косметика) — можно
  помечать старые незавершённые прогоны как `error: прервано` при старте.
- **Несколько воронок / валют** — сейчас одна целевая воронка
  (`AMOCRM_PIPELINE_ID`) и одна валюта. Расширяемо.
- **Ограничение доступа к AI-кнопке по роли** (сейчас доступна всем вошедшим) —
  при желании закрыть на marketer+.
- **Автотесты и CI** — см. `docs/09`.

## Соглашения

- **Язык интерфейса и комментариев** — русский (продукт для внутренней команды).
- **Числа** — форматируются Jinja-фильтрами (`money`, `pct`, `ratio`, `num`,
  `dur`), не в шаблонах вручную.
- **SQL** — параметризованный (`%s`), без конкатенации пользовательского ввода.
- **Фильтры** — только через `metrics.parse_filters(request.args)` и
  `metrics._deal_where(f)`; не дублировать построение `WHERE`.
- **Идемпотентность** — записи из amoCRM только через upsert по ключу; ручной
  ввод затрат — upsert по (месяц[, источник]).
- **Ничего на диск** — экспорт/вложения генерятся в память (`BytesIO`).
- **Синк не должен терять правки** — справочные поля, редактируемые человеком,
  не перезатирать при синхронизации.
- **Модель Claude** — `claude-opus-4-8` (константа `AI_MODEL`), официальный SDK
  `anthropic`. Идентификатор модели не хранить в артефактах, кроме конфигурации.
- **Графики** — Chart.js вендорится локально (`static/vendor/`), без CDN
  (строгая изоляция окружения Railway).

## Стиль кода

- Python: 4 пробела, компактные функции, говорящие имена, комментарии по делу.
- Шаблоны: макросы для повторяющихся строк таблиц; классы стилей — в
  `static/css/style.css` (не инлайнить стили без нужды).
- Именование файлов миграций: `NNN_snake_case.sql`.
